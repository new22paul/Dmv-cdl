# Тренажёр DMV для CDL

Приложение для телефона: диалог с сотрудником DMV Флориды при повышении прав до CDL
и подготовка к проверке английского на дороге (вопросы инспектора и дорожные знаки).
Вопросы звучат на английском, отвечать можно голосом или текстом. Работает без интернета после первого запуска.

Открыть: https://new22paul.github.io/Dmv-cdl/
